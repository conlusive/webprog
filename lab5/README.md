# Лабораторна робота №5 - кешуючий проксі-сервер на Node.js

Картинки беруться з https://http.cat і кешуються на диску.

    npm install
    npm start -- -h 127.0.0.1 -p 3000 -c ./cache

Методи: GET /<код>, PUT /<код> (тіло - картинка), DELETE /<код>. Інші методи - 405.
Команди для перевірки - у test.txt, колекція Postman - у теці postman/.
